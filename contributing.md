**Why people start here**

Choosing a build before knowing which feature you actually use is backwards. This
one lets you switch modules off one at a time and find the combination that fits
how you play, instead of guessing from a list.

**First-run order**

1. Extract to a folder you own — not `Program Files`, not `Downloads`.
2. Right-click the loader → **Run as administrator**.
3. Let the auto-updater finish before touching any tab.
4. Start with everything off, then enable one module per match.
5. Save the profile that works and name it.

**Performance note**

The overlay is the only component that costs frames. If you are chasing a stable
frame-time, turn off the skeleton layer first — it redraws bone chains every frame
and is by far the most expensive draw call in the pack.

**What this is not**

It is not a magic fix for a banned account. If the ban is account-side, no build
here changes that; the identity reset only helps when the ban is tied to hardware.

## 🆔 How the Spoofer Works

The spoofer is the module that makes a banned PC usable again.

**Order of operations**

1. Close the game and its launcher completely.
2. Run the loader as administrator.
3. Open the **Spoofer** tab and press **Spoof**.
4. **Reboot** — volume serial and SMBIOS are read at boot.
5. Create a fresh account and log in.

**What it does not do**

It does not unban the old account. It gives the machine a new identity so a new
account is not linked to the old ban.

**Skipping the reboot is the most common mistake** — people report "the spoofer
did nothing" when they simply never restarted.
